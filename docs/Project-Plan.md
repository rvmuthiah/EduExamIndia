# EduExam India (RankOne)

## Project Overview

EduExam India (RankOne) is an online examination platform designed for students from Class 6 to Class 12 across multiple educational boards in India.

## Supported Boards

- Tamil Nadu State Board
- Matriculation
- CBSE
- NCERT
- (Future) ICSE

---

## Project Objectives

- Online student registration
- Secure login using JWT
- PDF question paper upload
- AI-based question extraction
- Admin question approval
- Question Bank Management
- Online Exam Creation
- Student Dashboard
- Auto Evaluation
- Rank List
- Progress Reports
- Razorpay Payment Integration
- Email & WhatsApp Notifications
